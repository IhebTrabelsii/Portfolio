# Iheb Trabelsi — Full Stack Developer Portfolio

A multilingual, interactive portfolio website for Iheb Trabelsi, a full-stack developer based in Nabeul, Tunisia.

## 🌐 Languages Supported

- 🇬🇧 English
- 🇫🇷 French
- 🇸🇦 Arabic

## ✨ Features

- **Multilingual** — Switch between English, French, and Arabic with a click. Text, placeholders, and even the typewriter update dynamically.
- **RTL Support** — Arabic text automatically flips the layout to right-to-left.
- **Custom Cursor** — A smooth, branded cursor that expands on interactive elements.
- **Typewriter Effect** — Dynamic role display that updates with language changes.
- **Terminal Emulator** — A playful code‑block that types out a developer object.
- **Scroll‑Based Animations** — Reveal sections, parallax blobs, and a progress bar.
- **Magnetic Buttons** — Buttons subtly follow the mouse for an interactive feel.
- **Card Tilt** — Project cards tilt in 3D on hover.
- **Mobile‑First** — Fully responsive with a hamburger menu.

## 🛠️ Tech Stack

- **HTML5** / **Tailwind CSS** / **Custom CSS**
- **Vanilla JavaScript** (no frameworks)
- **Font Awesome** for icons
- **Google Fonts** (Fraunces, Inter, JetBrains Mono)
